What's new in v3 (concrete deltas, not vibes)

  1. Progressive disclosure on Row 1 · Cards ①–③ render headline + delta only. Hover for confidence; click for full pattern/roster. Card ④ (Action) is the only one with full inline context — confidence + impact + CTA, because that's where the decision lives.
  2. Confidence restraint · Inline only on insight cards, roster rows, action CTA. Sparklines and the new bars use the page-level badge in the header. Saved ~8 elements per page.
  3. Threshold citation · Page-level confidence now annotates the basis: "High (n=312 sub · 18d · Wilson CI ≤ 0.10)". The thresholds (n≥10 AND ≥14d = High) are derived from a Wilson score interval target of ≤0.10 half-width on the rolling CDS estimate, not arbitrary. To be cited in thesis Ch. 3.
  4. ImpactTag K-tier honesty · "Impact (directional, K=2): est. CDS −0.02 to −0.09" — label + widened range when K<5. Never a false-precision point estimate on small K. Range shrinks to point + 80% CI at K≥5.
  5. Field renamed pattern · From why_now. Renders observable pattern: "28 of 31 Ex-3 failures share the same off-by-one output, clustered within 48h." No causal claim.
  6. Integrity separated · Pulled out of the pedagogical Row 4. Now Row 5, dashed border, muted, collapsed by default. Subtitle: "separate epistemic mode — read before acting". This is the surveillance-vs-pedagogy boundary, drawn at the layout level.
  7. Radar → sortable bars · Class overview now uses a 7-concept horizontal bar list, sorted by CDS descending. Worst concept jumps out without shape distortion. Radar kept only for student "my skills" gestalt (where it's defensible).
  8. Signal cells → buttons · Roster SIGNAL column is now a micro-button ("⏱ 24m vs 11m ▸"). Clicking opens the interpretation panel, not a raw number view. Surveillance data, pedagogy surface.
  9. Teaching Insight template honesty · "View question template →" link points to the source file: lib/insights/loops/boundary_question_v1.md. Spec will document the ~15-template library, rule-mapped, hand-authored.
  10. "Why am I seeing this?" affordance · Click on the Teaching Insight → reveals the rule that fired (name, threshold, triggering inputs). This is the system showing its work — defense gold. The pattern description in the body is the result; the affordance is the proof.

Empty / early-term states (v2 unchanged, with v3 confidence wording)

  • Week 1: Teaching Insight hidden. Page-level confidence badge is "Low (n<10)". Every insight card ends with "Awaiting data" + a submission-driving CTA. Roster empty. Bars render with all 0.00 placeholders + a "No submissions yet" footer.
  • Mid-term, all clear: Teaching Insight reads "Class is on track across all 7 concepts — no concept > 0.31 CDS this week." Confidence High. Roster empty. The page proves it can be quiet without being empty.
  • Low-N class (<5 students): Page-level confidence Med. Every card footer reads "Small-N section · patterns may shift as more students enroll." ImpactTag falls back to "—" with "Not enough history to estimate impact".

Why v3 is publishable, not just presentable (the line for the spec)

v3 closes the four failure modes a thesis panel will probe: causal overreach (renamed pattern, no inference) · statistical bluffing (Wilson-anchored thresholds, cited) · false-precision impact (K-tier ranges, never a point on K<5) · surveillance reframed (signals as pedagogy, integrity as its own mode, signal cells open interpretations not raw numbers). The "Why am I seeing this?" affordance on the Teaching Insight is the single strongest defense artifact: a system that shows its rule is auditable. The five additions are no longer decorative; each one has a citation, a threshold, and a fallback.

Does v3 land — with the feedback woven in? If yes, Section 4 (Student Learning Journey + Integrity Dashboard) is next, then the consolidated design doc.
