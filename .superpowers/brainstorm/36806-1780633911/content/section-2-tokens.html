Visual atoms. Dark-first, IDE-adjacent, insight-first. Six refinements from the v1 review: CDS trend colors, RiskBadge, InterventionCard, ConceptMasteryRadar, Professional Light theme, and the "Learning Insights Language" hard rule.

HARD RULE — LEARNING INSIGHTS LANGUAGE
Never display CDS values without context. Every CDS visualization must explain what the score means, why it matters, and what action should be taken. Bare numbers like CDS = 0.62 are a code-review rejection.
CDS: 0.62 (High Difficulty)  —  Students are struggling with nested loops. Average completion time increased 18%.
The trailing clause (what + why + action) is non-optional. The intervention card / insight caption is the canonical surface for it.

Insight-first, restated (now with Learning Insights Language)

  • <InsightCard insight={...} chart={...} drillTo={...} /> is the canonical analytics pattern. Reading order: Insight (1 sentence, includes what/why/action) → Chart (evidence) → Drill (next question).
  • CDSPill now ships as CDSPillDelta by default in analytics contexts (timeline, intervention, command hub). Bare CDSPill is allowed only in dense tables where the trend is the same column for every row.
  • RiskBadge consolidates the "needs help" signal that was previously split across CDS classification + flag count. One badge per student per view, color = highest severity.
  • InterventionCard is the only component allowed to call a primary action on a student. Everywhere else, "Suggested:" is text-only.
  • Empty states always have a "what should I do?" CTA, never just "No data."
